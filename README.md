## 运营商江湖：三足鼎立与群雄割据

　　澳洲的移动网络市场有点像三国演义，Telstra、Optus、Vodafone各占一方。但话说回来，对我们用户而言，选择其实更多了。

*   **Telstra**：信号覆盖的王者，尤其是当你计划去偏远地区、国家公园或者自驾大洋路时，它的优势就体现出来了。价格通常也是最贵的，适合对网络稳定性有硬性要求的人。旗下的Belong品牌是主打性价比的平价选择。
*   **Optus**：在城市和主要城镇地区，它的网络质量和Telstra相差无几，但价格更亲民一些。套餐往往附带一些流媒体会员之类的福利，年轻人用的比较多。我觉得它的店面分布很广，办业务方便。
*   **Vodafone**：城市里的表现不错，套餐价格通常最有竞争力，主打一个便宜大碗。但一旦离开城市核心区，信号衰减会比较明显。如果你主要待在悉尼、墨尔本等大城市，Vodafone是个不错的省钱选择。

　　想象一下，你正在乌鲁鲁巨石脚下，朋友在发朋友圈定位，而你的手机却显示“无服务”——这种时候你就会明白网络覆盖的价值了。

## MVNO：高性价比的幕后英雄

　　除了三大运营商，你还会看到一大堆像Amaysim、Kogan、Boost Mobile这样的牌子。这些是虚拟运营商（MVNO），他们租用三大的网络，然后推出更便宜的套餐。

　　这有点像你自己装宽带，网络是电信的，但给你提供服务的是另一家公司。好处是价格真香！同样的流量，可能比直接买三大的便宜三分之一。但有一点需要注意：在网络繁忙时，你的数据优先级可能会比直接使用三大网络的用户低那么一点点（网络资源调度策略）。不过对于绝大多数日常使用，你根本感觉不出来。

## 2025年套餐价格一览

　　现在的套餐，数据量给得是越来越大方了。价格这东西变动快，但2025年初的市场行情大致是这样的：

*   **经济型（20-30澳元/月）**：通常能拿到40GB - 60GB的数据，无限通话和短信。多数MVNO在这个区间。
*   **标准型（35-45澳元/月）**：数据量往往在80GB到150GB之间，有时会捆绑Disney+或Spotify等订阅服务。三大运营商的主力套餐在这。
*   **无限数据（50-60+澳元/月）**：通常是真的无限数据，或者前几百GB是高速流量。

　　注意啦，这些都是预付费（Prepaid）套餐的价格。签手机合约（Postpaid）的话，会复杂一些，需要提供本地身份和信用记录，对 newcomers 来说，预付费是更简单直接的选择。

## APN设置与频段兼容性：搞定它才能上网

　　你有没有遇到过？卡插进去了，信号满格，但就是上不了网？八成是APN没设置对。

　　大多数情况下，插卡后运营商会自动下发配置信息。但偶尔会失灵，这时候就需要手动设置APN了。操作很简单：在手机网络设置里找到APN选项，新建一个，然后输入运营商提供的APN名称（比如Telstra是`telstra.wap`）。这个信息在运营商官网的帮助页面一定能找到，存个书签备用吧。

　　关于频段，澳洲主要使用4G的B3, B7, B28和5G的n78等频段。现在市面上99%的手机都支持这些主流频段，所以不用太担心兼容性问题。除非你用的是一款非常冷门的老机型。

## 合规与实名：Recharge ID是什么？

　　从2023年底开始，澳大利亚所有预付费手机卡都需要进行实名登记，这叫Recharge ID。购买SIM卡后，你需要通过运营商的App或网站，上传护照等身份证件信息来完成验证，之后才能正常激活使用。

　　这不是什么麻烦事，反而是为了通信安全。记得尽快完成，别等要用了才发现卡被锁了。

## 给短期旅行者的备选方案

　　如果你只是来玩一两周，换张本地卡可能嫌麻烦。两个备选思路：

1.  **开通本国手机号的国际漫游**：价格贵，但省心，能接到所有原来的电话短信。
2.  **购买区域数据包**：有些运营商提供“亚太地区多国通用”的流量包，适合同时游玩多个国家的旅行者。

　　不过说实话，对于超过一周的行程，买张本地预付费卡通常是最经济、流量最管够的方案。
